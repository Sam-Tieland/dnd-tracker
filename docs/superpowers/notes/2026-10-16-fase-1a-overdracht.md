## Open vragen voor Sam (PHB-controle)

1. Eldritch Knight en Arcane Trickster gebruiken Intelligence voor spellcasting.
2. Alleen gebruikt horen hun spell slots bij caster-level `ceil(level / 3)` (Eldritch Knight 7: 4 slots van level 1, 2 van level 2).
3. In een multiclass tellen ze voor `floor(level / 3)`.
4. Paladin + Ranger samen: de SRD zegt "Half your levels (round up) in the Paladin and Ranger classes". De code rondt per class af (Paladin 3 + Ranger 3 → 2 + 2 = 4); beide levels samen halveren zou 3 geven.

Klopt een punt niet: pas `SKELETON_SUBCLASSES` of `casterLevel` aan, met een test die de juiste waarde vastlegt.
